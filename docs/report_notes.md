# Report Notes

## 作品名

FretTone Camera Sync

## 概要

Raspberry PiカメラまたはPCカメラで撮影したギター指板画像をもとに、画像上の座標を弦番号・フレット番号へ変換するプロトタイプです。

現段階では指先の自動検出までは行わず、画像上でクリックした位置を仮の押弦位置として扱います。クリック座標を、キャリブレーション済みの指板領域に対して透視変換し、仮想的な長方形の指板座標へ変換します。その後、縦方向を6弦分、横方向を表示フレット数分に分割し、何弦・何フレット付近かを推定します。

## 制作目的

ギター学習では、タブ譜や画面上の指板図を見ても、それが実際のギター上のどの位置に対応するのかを直感的に理解しにくい場合があります。

この作品では、実物のギター指板と画面上の指板表示を対応づけるための基礎として、カメラ画像上の位置情報を音楽的な座標である「弦番号」と「フレット番号」に変換する仕組みを作成しました。

将来的には、FretTone本体の指板表示や音名・度数表示と連携し、表示された音を実際に正しく押さえられているかを判定する練習支援ツールへ発展させることを想定しています。

## 現在実装できていること

* サンプル指板画像の読み込み
* 指板範囲の4点キャリブレーション
* 内部フレット線の個別キャリブレーション
* キャリブレーション結果のJSON保存
* 画像座標から仮想指板座標への透視変換
* クリック位置から弦番号・フレット番号を推定
* 推定結果の画面表示とターミナル出力
* PCカメラやUSBカメラのライブ映像上でのクリック推定
* MIDI番号から現在の4フレット窓内の弦・フレット候補を列挙
* USBマイクまたはPCマイクからの単音ピッチ推定

## 処理の流れ

```text
1. 指板画像を読み込む
2. 指板の左上、右上、右下、左下の4点をクリックする
3. 4点をもとに、斜めに写った指板を仮想的な長方形へ変換する
4. クリック位置を同じ変換行列で仮想指板座標へ移す
5. 仮想指板を6弦分に区切り、フレットは保存済み境界または等分割で判定する
6. クリック位置が入った区画から弦番号・フレット番号を推定する
```

## 工夫した点

* 撮影角度で指板が斜めに写っても扱えるよう、OpenCVの透視変換を使った
* 座標変換の処理を `fretboard_position_mapper.py` に分離し、画像テスト版や将来のカメラ版から再利用できる形にした
* キャリブレーション点をJSONとして保存し、毎回同じ設定を読み込めるようにした
* 内部フレット線を追加で指定できるようにし、等分割より実際の見え方に近い推定を選べるようにした
* 弦の上下順や表示フレット範囲を設定値として変更できるようにした
* 標準チューニングの音高テーブルを分離し、将来のマイク音高推定と接続しやすくした

## 現在の制限

* 指先位置は自動検出ではなく、クリックで代用している
* ライブカメラ映像での指先自動追跡は未実装
* フレット線の自動検出は未実装で、必要な場合は手動クリックで指定する
* 音名推定は単音プロトタイプ段階で、ノイズやコード演奏には未対応
* 複数音やコード演奏には未対応

## 今後の発展

* 指先位置を画像処理で自動検出する
* フレット線を自動検出し、キャリブレーション操作を減らす
* Raspberry Pi Camera Module向けの専用対応を追加する
* USBマイクで鳴った音高推定の精度を上げる
* カメラで推定した押弦位置と、マイクで推定した音名を照合する
* FretTone本体の画面上指板と連携し、実際の押弦位置をリアルタイムに表示する

## デモ手順

```bash
python src/fretboard_calibration.py
```

表示された画像上で、認識したい指板範囲の4隅を左上、右上、右下、左下の順にクリックします。`s` キーで `data/calibration_points.json` に保存します。

必要に応じて、4隅のあとに内部フレット線を左から順にクリックします。内部フレット線まで指定した場合、推定時は等分割ではなく保存したフレット境界を使います。

```bash
python src/run_with_image.py
```

画像上の指板をクリックすると、クリック位置が何弦・何フレット付近かを画面とターミナルに表示します。

ライブカメラで確認する場合:

```bash
python src/run_with_camera_pi.py
```

`c` キーでカメラ映像上のキャリブレーションを開始し、指板の4隅を左上、右上、右下、左下の順にクリックします。必要に応じて内部フレット線もクリックし、`s` キーで保存します。

保存後は、ライブ映像上の指板をクリックすると、クリック位置が何弦・何フレット付近かを画面とターミナルに表示します。

カメラ版のキャリブレーションは、サンプル画像版とは別に `data/camera_calibration_points.json` へ保存します。これにより、サンプル画像で指定した枠がライブ映像に残らないようにしています。

カメラ映像の向きが実際の操作感と合わない場合は、`--flip horizontal` などのオプションで反転できます。実行中は `f` キーで反転モードを切り替えられます。反転後は表示座標が変わるため、再キャリブレーションが必要です。

ライブカメラ版では、キャリブレーションした指板範囲内の外周寄り特徴点をオプティカルフローで追跡し、RANSACで外れ値を除外しながらギターの小さな移動に枠を追従させます。手に引っ張られて枠が大きくずれることを避けるため、急な拡大縮小や大きな移動は追従せず `track:lost` として扱います。追跡は `t` キーで切り替えられます。大きく動かした場合や指板の特徴点が大きく隠れた場合は、再キャリブレーションが必要です。

音高候補を確認する場合:

```bash
python src/run_note_candidates.py --midi-pitch 62 --start-fret 5 --visible-frets 4
```

この例では、5〜8フレット窓内で MIDI 62、つまり D4 に一致する弦・フレット候補を表示します。

指板図だけを表示する場合:

```bash
python src/run_fretboard_display.py --start-fret 5 --visible-frets 4 --total-frets 12 --block-size 4
```

表示された指板をクリックすると、その弦・フレットが黄色く光ります。
指板図は12フレット全体を表示し、4フレットずつの3ブロックに分けて表示します。
現在対象になっているブロックは黄色い枠で強調されます。
`a` / `d` キーで現在ブロックを4フレットずつ左右に動かせます。

カメラ推定位置と音高候補を照合する場合:

```bash
python src/run_note_candidates.py --midi-pitch 64 --start-fret 5 --visible-frets 5 --estimated-string 2 --estimated-fret 6
```

サンプル画像上のクリック位置と仮のMIDI番号を照合する場合:

```bash
python src/run_with_image.py --midi-pitch 62 --start-fret 5 --visible-frets 4
```

ライブカメラ上のクリック位置と仮のMIDI番号を照合する場合:

```bash
python src/run_with_camera_pi.py --flip horizontal --midi-pitch 62 --start-fret 5 --visible-frets 4
```

クリック後、カメラ画面左上とターミナルに音高照合結果が表示されます。
`--midi-pitch` を使う場合はUSBマイクや外部MIDI入力を使わず、指定した仮MIDI番号を固定値として使います。
実行中は `[` / `]` キーで、仮MIDI番号を半音ずつ下げたり上げたりできます。

マイク単体で音高推定を確認する場合:

```bash
python src/run_audio_pitch.py
```

入力デバイスを確認する場合:

```bash
python src/run_audio_pitch.py --list-devices
```

ライブカメラ上のクリック位置とマイク音高を照合する場合:

```bash
python src/run_with_camera_pi.py --flip horizontal --audio-pitch --start-fret 5 --visible-frets 4
```

この音声入力はWindowsデモ環境でも確認できますが、本番ではRaspberry Pi上のUSBマイク入力として使う想定です。

通常のマッピング中は、カメラ映像ではなく作成した仮想指板を表示します。
推定された押弦位置、または音高照合で選ばれた弦・フレットが黄色く光ります。
12フレット全体の中で、4フレットずつの3ブロック境界と現在ブロックも表示します。
キャリブレーション中は4隅を指定する必要があるため、カメラ映像を表示します。
実行中は `v` キーで仮想指板表示とカメラ表示を切り替えられます。

ギター同期のON/OFFを確認する場合:

```bash
python src/run_with_camera_pi.py --no-gpio
```

Windowsデモ環境では `o` キーで同期をON/OFFできます。
本番のRaspberry Piでは、タクトスイッチとLEDをGPIOへ接続して管理する想定です。

```bash
python src/run_with_camera_pi.py --gpio-button-pin 17 --gpio-led-pin 27
```

カメラやマイクなしでタクトスイッチとLEDだけを確認する場合:

```bash
python src/run_sync_gpio_test.py --gpio-button-pin 17 --gpio-led-pin 27 --demo-events
```

同期ON中は、音声入力と画面上で光った指板位置を以下へ保存します。

```text
data/sync_sessions/sync_YYYYMMDD_HHMMSS/
├── audio.wav
├── video.mp4
├── events.json
├── frame_times.json
└── meta.json
```

保存した同期セッションを後から確認する場合:

```bash
python src/run_sync_playback.py --latest
```

再生画面では、録音音声に合わせて保存済みの指板ハイライトが再表示されます。
`space` で再生/一時停止、`r` で最初から再生、`q` で終了できます。
